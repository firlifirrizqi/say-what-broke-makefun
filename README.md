# Say What Actually Broke

One honest, funny line of error copy, written for the [Make.fun bounty](https://make.fun/bounty/u-po-pu-say-what-actually-broke-a2c153b5).

`main.py` writes the line to `/output/entry.txt`:

> Payment failed: your card expired in 2023, and we have been too polite to mention it for two years. Please update it.

Run it with `python3 main.py`.
